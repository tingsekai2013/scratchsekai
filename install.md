## IOS

#### 1. downloading needed files
#### for ios you'll need the following.
- Open web view shortcut(included with the github)
- ScratchSekai You can get the file [here](https://github.com/tingsekai2013/scratchsekai/releases/)
> [!IMPORTANT]
> if your on an iphone it is recommended to use the lite version so it doesn't crash ipad runs fine with the main one

> [!tip]
> install scratchSekai.16_9.Lite.html for phones

#### 2. Installing the shortcut
- after you downloaded the Open.Web.View.shortcut you go to files and click on it it should open the shortcut app than just press Add shortcut button

#### 3. running the file
- start the shortcut than pick the html file you've downloaded than enjoy!
